# Security Policy

## Scope

This repository contains analysis code, configuration and public open data. It does not
process real patient, incident, ambulance or household data, and it must not be used to
do so. Start points used in examples are synthetic.

## Reporting a vulnerability

If you find a security problem (for example a leaked credential, a vulnerable
dependency, or a workflow that could be abused), please report it privately through
[GitHub private vulnerability reporting](https://github.com/khalilurrrahmanridoykhan/emergency-route-finder/security/advisories/new)
instead of opening a public issue.

You can expect an acknowledgement within a few days. This is a small research and
demonstration project, so there is no formal service level.

## Not a safety-critical system

Routes, times and facility recommendations produced here are model outputs based on
public data and stated assumptions. They are not for real emergencies and must not be
used to make real dispatch or care decisions.
