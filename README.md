# Emergency Route Finder

Flood-aware emergency referral routing for Sunamganj, Bangladesh, built on
[WHO AccessMod](https://github.com/unige-geohealth/accessmod).

For a starting point, an emergency type and a season (dry or flood), the goal is to
report the right facility, the travel time, the path, the travel mode, a backup
facility and any warning.

**Status:** work in progress. See `docs/ROADMAP.md` once the scaffold lands.

**This is an analysis and demonstration project. It is not for real emergencies.**
